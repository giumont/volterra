# Volterra Predator-Prey Simulator in C++
**Author:** *Giulia Montagnani*  

This project implements a **basic numerical simulation** of the *[Lotka–Volterra predator-prey model](https://en.wikipedia.org/wiki/Lotka%E2%80%93Volterra_equations)* in C++.  
The simulation uses a **simple discrete method** (Euler solver) to solve the coupled differential equations over a specified time interval, and generates output files that represent the **evolution of the populations**.

**DISCLAIMER**: Developed as part of a university programming course, the project follows course guidelines, which include using a simple Euler solver. This choice reflects course requirements rather than a design decision. The focus is on **implementation and code design**, and the project is intended for educational purposes rather than practical applications.
